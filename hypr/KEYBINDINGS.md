# Hyprland Keybindings

> `$mod` = Super (Windows key)

---

## Apps

| Key | Action |
|-----|--------|
| `Super + Enter` | Terminal (Kitty) |
| `Super + T` | Terminal (Kitty) |
| `Super + M` | App launcher (Rofi) |
| `Super + B` | Browser (Firefox) |
| `Super + E` | File manager (Thunar) |
| `Super + V` | Clipboard manager (CopyQ) |
| `Super + L` | Lock screen (Hyprlock) |
| `Super + Escape` | Power menu (wlogout) |
| `Super + I` | Network manager |
| `Super + Z` | Zed editor |
| `Super + W` | Toggle Waybar |

---

## Windows

| Key | Action |
|-----|--------|
| `Super + Q` | Close focused window |
| `Super + F` | Fullscreen / maximize |
| `Super + D` | Toggle floating |
| `Super + ←` | Focus left |
| `Super + →` | Focus right |
| `Super + ↑` | Focus up |
| `Super + ↓` | Focus down |
| `Super + Shift + ←` | Move window left |
| `Super + Shift + →` | Move window right |
| `Super + Shift + ↑` | Move window up |
| `Super + Shift + ↓` | Move window down |
| `Super + Ctrl + ←` | Resize window left (-30px) |
| `Super + Ctrl + →` | Resize window right (+30px) |
| `Super + Ctrl + ↑` | Resize window up (-30px) |
| `Super + Ctrl + ↓` | Resize window down (+30px) |
| `Super + Mouse Left` | Drag / move floating window |
| `Super + Mouse Right` | Resize floating window |

---

## Workspaces

| Key | Action |
|-----|--------|
| `Super + 1-9, 0` | Switch to workspace 1–10 |
| `Super + Shift + 1-9, 0` | Move window to workspace 1–10 |
| `Super + Tab` | Next workspace |
| `Super + Shift + Tab` | Previous workspace |
| `Ctrl + Alt + →` | Next workspace |
| `Ctrl + Alt + ←` | Previous workspace |
| `Ctrl + Super + Alt + →` | Move window to next workspace |
| `Ctrl + Super + Alt + ←` | Move window to previous workspace |
| `Ctrl + Shift + Alt + ←↑↓→` | Focus an empty workspace |
| `Ctrl + Shift + Alt + Super + ←↑↓→` | Move window to empty workspace |
| `Super + S` | Toggle special workspace (magic) |
| `Super + Shift + S` | Move window to special workspace |

---

## App Switcher

| Key | Action |
|-----|--------|
| `Alt + Tab` | App switcher across all workspaces (Rofi window mode) |

---

## Screenshots

| Key | Action |
|-----|--------|
| `Print` | Region screenshot → swappy |
| `Super + Print` | Full screen screenshot → swappy |
| `Super + Shift + Print` | Focused window screenshot → swappy |

> Saved to `~/Pictures/Screenshots/`

## Screen Recording

| Key | Action |
|-----|--------|
| `Super + F9` | Toggle region screen recording |
| `Super + F10` | Toggle full screen recording |

> Saved to `~/Videos/Screencasts/`

## Volume

| Key | Action |
|-----|--------|

| `Volume Down` | Lower volume -5% |
| `Mute` | Toggle audio mute |
| `Mic Mute` | Toggle microphone mute |
| `Ctrl + M` | Toggle microphone mute |
